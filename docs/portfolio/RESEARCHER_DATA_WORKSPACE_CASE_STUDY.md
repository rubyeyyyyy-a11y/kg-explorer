# Researcher Data Workspace — 产品案例

医学研究者常拥有可共享或受限共享的结构化研究数据，却只能阅读平台的既有知识图谱。只读图谱不足以帮助他们验证自己的实体、关系和证据如何形成可探索的研究脉络。

本方案采用 **Private Exploration + Governed Contribution**：先在隔离的浏览器工作区中，以自己的 CSV 生成临时图谱；只有当研究者希望贡献时，才提交进入未来的结构、内容质量、来源与授权审核。这样既让数据拥有者立即获得图谱探索能力，也避免未经治理的数据直接污染共享知识图谱。

Schema Mapping 复用原 KG 的 Entity/REL2 字段，降低研究者理解内部命名的成本，并明确 Entity Description 与关系 Evidence 的不同归属。数据质量校验在提交前展示可操作的行级问题；私有预览的端点完整性检查保证用户实际能看到完整局部图谱。

Demo 已实现本地 CSV 处理、映射、质量校验、G6 私有预览、节点/关系查看、PMID/DOI 外链与本地演示提交。未来真实版本需要安全上传、访问控制、服务端 Draft/Job、失败行报告、审核队列、授权记录、版本/溯源和审批后的受控写入。这里没有声称完成过用户访谈、竞品调研或实际平台入库。
